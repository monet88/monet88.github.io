2. Setup Từ Đầu Đến Cuối (Làm 1 lần ~25 phút)

Bước 1 — Cài Anki Desktop + bật FSRS + cài AnkiMCP add-on

  1. Tải và cài Anki Desktop (bản 25.x trở lên, hiện tại là 26.09.4; cần bản mới vì AnkiMCP add-on chạy trên Python 3.13 của Anki 25+). Tạo 1 tài khoản AnkiWeb miễn phí để đồng bộ điện thoại.
  2. Bật thuật toán FSRS (bắt buộc, hiệu quả hơn SM-2 cũ 20–30%):
    • Trong Anki, bấm biểu tượng bánh răng cạnh Deck → Options.
    • Kéo xuống mục FSRS → gạt bật FSRS, giữ Desired retention ở mức 0.90, mục New cards/day đặt 10 (hoặc 12), Maximum reviews/day đặt 9999 (không ẩn thẻ tồn).
    • Ở phần Display Order → New card gather order, nếu dùng deck câu tăng dần (như Forkfed) thì chọn Deck / Ascending position.
  3. Cài AnkiMCP Add-on (chạy sẵn HTTP MCP server ngay bên trong Anki — không cần cài Node.js hay AnkiConnect riêng):
    • Mở Anki → Tools → Add-ons → Get Add-ons…
    • Nhập mã: 124672614 → OK → khởi động lại Anki.
    • Mặc định server local tự chạy tại http://127.0.0.1:3141/ mỗi khi Anki đang mở.
  4. (Tùy chọn nếu muốn có sẵn bộ thẻ chuẩn ngay):
    • Ưu tiên giao tiếp tự nhiên: tải Forkfed_Chinese.apkg từ oatlayers/forkfed (7.326 câu có audio chuẩn, đã sửa 1.278 lỗi pinyin & có biến điệu PinyinSandhi).
    • Ưu tiên bám đề thi HSK 3.0: tải deck HSK 3.0 (2025) từ krmanik/Anki-xiehanzi (hỗ trợ vẽ nét Hanzi Writer ngay trong thẻ).
    • Hoặc không cần tải deck lớn: tạo 1 deck trống tên Chinese::Daily rồi để Agent (AGY/Codex) tự bơm 10 thẻ chuẩn HSK 3.0 mỗi ngày từ HSK MCP.

Mẹo hiển thị Anki: Nếu import deck lớn (như Forkfed hoặc Anki-xiehanzi), vào Browser chọn các thẻ chưa học bấm Toggle Suspend (Ctrl+J) nếu muốn tự mở khóa dần, và ẩn Pinyin ở mặt trước khi đã quen đọc chữ Hán.

Bước 2 — Cài bộ công cụ bổ trợ (Điện thoại + Windows + Chrome)

  • Điện thoại (iOS/Android): cài Pleco (tra viết tay), Hanzii (nghĩa Việt + Hán–Việt), và Hanly (học cấu tạo chữ Hán như xếp LEGO).
  • Chrome / Edge trên Windows: cài extension Zhongwen (hover chuột vào chữ Hán trên bất kỳ trang web nào là hiện Pinyin tô màu thanh điệu + nghĩa; bấm G để mở thẳng ngữ pháp).
  • Bộ gõ Pinyin trên Windows: vào Settings → Time & language → Language & region → Add a language → Chinese (Simplified, China) để cài Microsoft Pinyin. Quy tắc nhớ nhanh: gõ v thay cho ü (ví dụ gõ lv ra 绿 / 女 gõ nv).

Bước 3 — Nối MCP vào AGY, Codex và ChatGPT Business

Ta dùng 2 MCP cốt lõi miễn phí không cần API key, cộng thêm 1 MCP TTS miễn phí ở local nếu muốn Agent tự đẻ file MP3 gắn vào Anki:

  • AnkiMCP local: http://127.0.0.1:3141/ (cần mở Anki Desktop khi dùng).
  • HSK MCP Server (Remote HTTP, 0đ, 11.470 từ HSK 3.0 & 2.0): https://hsk-mcp.linsnotes.com/mcp (kiểm tra sống/chết bằng curl https://hsk-mcp.linsnotes.com/healthz).
  • TTS MCP (Local, sinh MP3 Edge-TTS miễn phí): cài bằng Python (tùy chọn):

3A. Cấu hình cho Antigravity CLI (agy)

Mở (hoặc tạo) file cấu hình global %USERPROFILE%\.gemini\config\mcp_config.json và gộp các mục sau vào mcpServers:

{
  "mcpServers": {
    "anki": {
      "url": "http://127.0.0.1:3141/"
    },
    "hsk": {
      "url": "https://hsk-mcp.linsnotes.com/mcp"
    },
    "tts-server": {
      "command": "tts-mcp",
      "args": [],
      "env": {
        "TTS_OUTPUT_DIR": "D:\\chinese-audio"
      }
    }
  }
}

Nhớ tạo trước thư mục D:\chinese-audio (hoặc đổi sang thư mục Đại Ca thích) nếu bật tts-server; không cài tts-mcp-server thì bỏ hẳn block "tts-server" đi, anki và hsk vẫn chạy độc lập.

3B. Cấu hình cho OpenAI Codex CLI

Chạy lần lượt trong PowerShell (tự ghi vào ~/.codex/config.toml):

codex mcp add anki --url http://127.0.0.1:3141/
codex mcp add hsk --url https://hsk-mcp.linsnotes.com/mcp
codex mcp list

Nếu đã cài tts-mcp-server[edge], thêm tiếp vào ~/.codex/config.toml:

[mcp_servers.tts-server]
command = "tts-mcp"
args = []

[mcp_servers.tts-server.env]
TTS_OUTPUT_DIR = "D:\\chinese-audio"

3C. Cấu hình cho ChatGPT Business Web & App Voice

  1. Bật Tunnel trong Anki: mở Anki → Tools → AnkiMCP Server Settings… → Connect Tunnel → đăng nhập OAuth 1 lần trên trình duyệt. Địa chỉ tunnel chung của Đại Ca sẽ là https://tunnel.ankimcp.ai/mcp (chỉ hoạt động khi đăng nhập đúng tài khoản OAuth của Đại Ca và Anki đang mở).
  2. Thêm vào ChatGPT Business Web (chatgpt.com):
    • Nếu chưa thấy nút tạo MCP, bật Developer mode trong Settings → Security / Connectors (lưu ý: trên workspace Business, quyền bật Developer mode & thêm custom MCP do Admin/Owner workspace quản lý).
    • Vào Plugins / Apps & Connectors → Add → Create MCP App:
      • Connector 1: Name AnkiMCP · Server URL https://tunnel.ankimcp.ai/mcp · Authentication: OAuth → Accept & Grant Access.
      • Connector 2: Name HSK-Dict · Server URL https://hsk-mcp.linsnotes.com/mcp · Authentication: không cần / None.
      • (Tùy chọn): Connector 3: Name Chatterbox · Server URL https://mcp.chatterboxlabs.io/mcp · Authentication: OAuth (tài khoản Chatterbox miễn phí).
  3. Lưu ý riêng cho ChatGPT Voice: Theo tài liệu của AnkiMCP, trong app/web ChatGPT chọn Settings → Voice. Nếu chế độ Live không gọi được custom connector trong lúc nói, chuyển sang model Standard hoặc Advanced. Các thao tác ghi dữ liệu vào Anki có thể yêu cầu bấm nút xác nhận trên màn hình.

3. 4 Cái Bẫy Người Việt Phải Chặn Ngay Từ Tuần 1

Số liệu âm học bằng Praat trên 42 sinh viên Việt Nam (ICA, 01/2026) cho thấy lỗi thanh điệu chiếm 40,6%, thanh mẫu 34,4%, vận mẫu 25%. Đọc thuộc bảng dưới trước khi cày từ vựng:

Cái bẫy hay gặpThực tế tiếng TrungCách sửa nhanh (tự test tại nhà)
1. Đọc Pinyin theo chữ Quốc ngữ d ≈ t Việt; t ≈ th; h ≈ kh; c = ts bật hơi; x mặt lưỡi sau răng dưới; r uốn lưỡi êm (không phải d/gi Bắc). Đặt tờ giấy mỏng trước miệng: đọc 6 âm bật hơi p, t, k, q, ch, c giấy phải rung mạnh; đọc b, d, g, j, zh, z giấy đứng yên.
2. Nhầm zh/ch/sh với z/c/s và thiếu ü zh/ch/sh/r bắt buộc cong đầu lưỡi lên vòm cứng; sau zh/ch/sh/r/z/c/s, chữ i đọc gần ư. Âm ü (trong 女 nǚ, 去 qù, 学 xué) là lưỡi ở i nhưng tròn môi như u. Luyện các cặp tối thiểu: 是 shì vs 四 sì; 知 zhī vs 鸡 jī; 吃 chī vs 七 qī; 路 lù vs 绿 lǜ.
3. Gán dấu Việt vào 4 thanh điệu Thanh 4 (à) rơi gắt từ đỉnh xuống (KHÔNG phải dấu huyền). Thanh 3 (ǎ) khi đứng trước thanh khác chỉ đọc nửa thanh thấp; hai thanh 3 liền nhau thì thanh đầu đổi sang thanh 2 (你好 → ní hǎo). Không luyện thanh đơn lẻ lâu — chuyển thẳng sang luyện 20 cặp thanh điệu (Tone Pairs) và nhìn đường F0 trên Mandarin The Wild.
4. Tin mù âm Hán–Việt & đặt sai 的 Quy luật Hán–Việt giúp đoán ~2.251 từ HSK 3.0 (xem bảng chuyển âm Nhai HSK), nhưng có nhóm từ giả bạn đổi nghĩa hẳn (大家 = mọi người, 便宜 = rẻ, 医生 = bác sĩ). Định ngữ tiếng Trung luôn đứng trước danh từ (我的书 = tôi của sách). Đọc qua danh sách 47 từ Hán–Việt đánh lừa trên HanyuStep và luôn tra chéo câu ví dụ trong Pleco / HSK MCP.

5. Kho Câu Lệnh Mẫu Copy-Paste Hằng Ngày (AGY / Codex / ChatGPT)

5.1. Lệnh buổi sáng/tối trên AGY hoặc Codex — Soạn & nạp 10 thẻ mới HSK 3.0

Hãy mở AnkiMCP lấy danh sách các từ tôi đã có trong deck "Chinese::Daily" (hoặc kiểm tra thẻ đang có).
Sau đó gọi hsk_suggest_next ở cấp HSK 1 (scheme="new") để chọn ra 10 từ mới tiếp theo tôi chưa biết.
Với mỗi từ:
1. Dùng hsk_lookup và hsk_classifier lấy pinyin, bộ thủ, lượng từ (nếu là danh từ) và nghĩa chuẩn.
2. Viết 1 câu ví dụ thật ngắn (tối đa 8 chữ, kiểu i+1 dùng từ dễ), kèm pinyin, âm Hán–Việt từng chữ, nghĩa tiếng Việt và 1 dòng ghi chú ngắn bẫy phát âm/ngữ pháp cho người Việt.
3. Nếu tts-server đang bật, sinh file audio MP3 cho từng câu ví dụ vào thư mục audio rồi import vào Anki bằng storeMediaFile.
4. Gọi addNotes đẩy 10 thẻ vào deck "Chinese::Daily" (báo cáo preview trước khi ghi nếu cần).

5.2. Lệnh cuối tuần trên AGY hoặc Codex — Chữa các từ hay quên ("Leech Review")

Dùng AnkiMCP tìm tối đa 15 thẻ có số lần quên (lapses) cao nhất hoặc độ ổn định thấp nhất trong deck tiếng Trung của tôi.
Phân tích nguyên nhân dễ nhầm cho từng từ (chiết tự bộ thủ, so sánh chữ na ná nhau, cặp từ dễ lẫn thanh điệu, hoặc Hán–Việt đánh lừa).
Viết lại câu ví dụ mới sinh động hơn để thay thế hoặc bổ sung vào ghi chú của các thẻ đó.

5.3. Lệnh trên ChatGPT Business Voice — Khảo bài & Hội thoại theo đúng vốn từ Anki

Dùng AnkiMCP lấy 10 thẻ đang đến hạn hoặc mới thêm gần nhất trong deck tiếng Trung của tôi.
Đóng vai nhân viên quán ăn / đồng nghiệp Trung Quốc, trò chuyện với tôi bằng giọng nói chậm và câu cực ngắn CHỈ xoay quanh 10 từ đó cộng với từ HSK 1 cơ bản nhất.
Mỗi lượt chỉ hỏi 1 câu. Nếu tôi nói sai ngữ pháp (đặc biệt lỗi tiếng Việt), sửa ngắn gọn bằng tiếng Việt rồi bắt tôi lặp lại câu đúng. Cuối buổi hỏi tôi muốn rate_card từng thẻ thế nào trước khi ghi về Anki.

6. Xử Lý Lỗi Thường Gặp

Triệu chứngNguyên nhânCách xử lý nhanh
AGY / Codex / ChatGPT báo không kết nối được AnkiMCP Anki Desktop chưa mở, hoặc Anki bản cũ < 25.x, hoặc chưa bật Tunnel cho ChatGPT Web. Mở Anki Desktop; kiểm tra phiên bản ≥ 25.x; với ChatGPT Web vào Tools → AnkiMCP Server Settings… → Connect Tunnel kiểm tra trạng thái đang Connected.
ChatGPT Business không thấy nút Create MCP App Workspace Business bị Admin tắt Developer mode hoặc chặn custom MCP connector của thành viên. Nhờ Admin bật Developer mode trong workspace Business, hoặc bỏ qua bước nối Web — chạy toàn bộ AnkiMCP + HSK MCP trên AGY / Codex CLI ở máy local (vẫn đầy đủ 100% tính năng).
ChatGPT Voice nói chuyện bình thường nhưng không gọi được AnkiMCP Chế độ Live đôi lúc bỏ qua custom connector hoặc cần duyệt quyền ghi trên màn hình. Chuyển Voice model sang Standard hoặc Advanced (theo khuyến cáo tài liệu AnkiMCP), và test gọi thử bằng text @AnkiMCP fetch anki decks trước khi bật mic.
Bị dồn 200+ thẻ Anki sau vài ngày bận nghỉ học Mở lại thấy ngập thẻ cũ → dễ nản bỏ ngang. Trong Anki, đặt tạm New cards/day = 0 trong 3–5 ngày cho đến khi dọn sạch thẻ tồn; hoặc dùng Add-on FSRS Helper → Postpone để rải đều thẻ tồn ra nhiều ngày. Tuyệt đối không học thẻ mới khi thẻ tồn chưa về 0.
Dùng tts-mcp báo lỗi không ra MP3 hoặc Windows không tìm thấy lệnh Chưa cài gói [edge] hoặc Script folder của Python chưa có trong PATH. Chạy kiểm tra where.exe tts-mcp trong PowerShell; nếu chưa thấy thì trỏ command trong mcp_config.json / config.toml thẳng tới file tts-mcp.exe trong thư mục Scripts của Python/venv.
